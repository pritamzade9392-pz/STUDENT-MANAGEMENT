# Student Management System

A simple student management web app built with HTML, CSS, and JavaScript.

## Features

- Add new students
- Edit student records
- Delete students
- Search across records
- Dashboard summary cards
- Local browser storage persistence

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
